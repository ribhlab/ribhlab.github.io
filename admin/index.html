نشر منظم وآمن

المقالات المنشورة تظهر في الموقع بعد حفظ التغييرات ونجاح بناء GitHub Pages. المسودات لا تظهر في صفحات RibhLab، لكنها موجودة في مستودع GitHub العمومي ويمكن الاطلاع على ملفاتها هناك. لا تحفظ بيانات سرية. لا تُنشر مقالة دون نسخ مكتملة باللغات الثلاث ومصادر موثقة وصورة بحقوق استخدام واضحة.

تُحفظ ملفات المقال وتصنيفه والصورة والمراجع في عملية Git واحدة لتجنب تعارض بيانات الموقع.
