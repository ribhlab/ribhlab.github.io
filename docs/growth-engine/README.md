# RibhLab Growth Engine — zero paid advertising
## 30-day execution register
- Website: 7 local-language landing pages, 5 functional browser utilities, updated sharing page and sitemap. Track deploy and browser smoke test; never claim indexing before Search Console confirms it.
- Play ASO: 7 validated store locale texts; only add missing locales via Android Publisher. Preserve images, pricing and release. Hindi discovery experiment: draft only until actual app support and copy are reviewed.
- App: explicit share app and more apps actions; optional Google Play review request only after meaningful successful use, rate-limited; no incentives, review filtering, forced redirects or automatic insertion into users' documents.
- A/B experiment: Play Console listing experiment, one change at a time (short description first), control 50%, variant 50% if sufficient traffic; choose statistically supported winner, not a fixed promise. No public changes until experiment is configured in Console.
- Social: create actual app screen recording or clearly labeled actual screenshot slideshow; no fake UI, testimonials or claims. TikTok/Shorts/Reels: 15–25 seconds. Use only owner accounts and allowed community self-promotion.
- Cross-promotion: optional RibhLab apps directory, no forced interstitials or unrelated ads.
- Measure weekly: Play organic store visitors/install conversion/acquisitions, active users, uninstall rate, Android vitals, Search Console impressions/clicks, social views and outbound clicks. Compare by language; distinguish unavailable metrics from zero. No paid campaigns, paid APIs or purchase of installs.
